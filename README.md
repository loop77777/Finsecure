# FinSecure

Starter Java application organized under the `com.finsecure` package.

The Java sources use the standard Maven layout:

```text
src/main/java/com/finsecure/
```

## Requirements

- JDK 26
- Maven 3.9+

## Run

```text
mvn test
java -cp target/classes com.finsecure.app.FinSecureEngine
```
